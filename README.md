# Ganak – Online Calculator

Ganak is a simple, responsive online calculator built using HTML, CSS and JavaScript. It performs basic mathematical calculations through an easy-to-use interface.

## Features

- Addition, subtraction, multiplication and division
- Percentage calculations
- Decimal number support
- Clear (AC) and delete (DEL) functions
- Error handling for invalid calculations
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start performing calculations.

## Project Structure

```text
Ganak/
└── index.html
```

## Purpose

This project was created to practise HTML, CSS and JavaScript and understand how these technologies work together to build an interactive web application.
